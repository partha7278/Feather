Backup

A consistent snapshot of feather's whole database — the archive catalogue, the administrator logins and the sealed credentials — taken while feather keeps running. This is what you restore from after losing the server. Copying the database file instead is not safe: it is written ahead of itself, so a plain copy captures a half-finished state.

A full path on the server. Left blank, feather names one with today's date beside the database. An existing file is never overwritten.

The backup needs the master key at {{.Data.MasterKeyPath}} to be read. Keep a copy of that key wherever you keep the backup — without it the file cannot be opened, and neither can the archives it points to.

Export & import

Every MongoDB account, every destination, every retention config and the settings above, as one file. This is for moving an installation to another server — it deliberately does not carry the archive catalogue or the administrator logins, so it is not a backup.

Export

At least {{.Data.MinPassphrase}} characters. Connection strings and cloud secrets are re-sealed under it, so the file is safe to keep off this machine — and useless without the passphrase. Store it somewhere you will still have it.
