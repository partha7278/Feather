Identity

Letters, numbers, dots, dashes and underscores. Used in file names and on the command line.

Source

Which documents this config is about.

Ordinary MongoDB Extended JSON — $lt, $in, $and, $oid, $date all work. Relative time tokens resolve on every run: {{"{{now}}"}}, {{"{{now-90d}}"}}, {{"{{now-6h}}"}}. An empty filter combined with deletion is rejected — that would empty the collection.

Optional. Recorded per archive file as its date range, which is what makes "where did January go?" answerable.

Reading from a secondary keeps the archive scan off the primary.

Projection (optional)

Leave blank to archive whole documents. A projection that drops fields makes the archive lossy — only useful when you are certain.

Destinations

Each one gets a complete copy. If any copy fails, nothing is deleted.

After archiving

The one setting on this page that destroys data.

Documents per delete command. Smaller batches are gentler on a busy primary.

Schedule

Forms like 30m, 6h, 2d. Anchored on the last completed run, so restarts do not reset the cycle.

Only meaningful when the interval is 24h or more.

Standard five-field cron. Prefer an interval: cron cannot express "every 2 days" without a gap at month boundaries.
