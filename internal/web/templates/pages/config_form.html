General

What the config is called, and whether the scheduler runs it.

Letters, numbers, dots, dashes and underscores. Used in file names and on the command line.

Source

Which documents this config is about.

MongoDB Extended JSON. The condition of a SQL WHERE clause; empty means every row. Relative time tokens such as {{"{{now-90d}}"}} resolve on every run.

Filter reference

Operators like $lt, $in, $and, $oid and $date all work. Time tokens: {{"{{now}}"}}, {{"{{now-90d}}"}}, {{"{{now-6h}}"}}.

Any condition PostgreSQL accepts, subqueries included: created_at < {{"{{now-90d}}"}} AND status IN ('closed', 'void'). A bare token becomes TIMESTAMPTZ '…'; inside quotes it becomes the timestamp text. Because the same condition guards every delete, semicolons, -- and /* */ comments, $ parameters, E'…' strings and unbalanced parentheses are refused. The table needs a single-column primary key.

Optional. Recorded per file as its date range, which is what makes "where did January go?" answerable.

Reading from a secondary keeps the archive scan off the primary.

Projection (optional)

Leave blank to archive whole documents. A projection that drops fields makes the archive lossy — only useful when you are certain.

Schedule

When the config runs.

e.g. 30m, 6h, 2d.

For intervals of 24h or more.

Five fields. Prefer an interval for "every N days".
